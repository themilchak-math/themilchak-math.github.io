설치 방법

  1. 사파리(Safari)로 열기카톡 안에서 열렸다면 오른쪽 아래 ⋯ 또는 공유 버튼 → Safari로 열기를 눌러 주세요.
  2. 아래 [앱 열기] 버튼 누르기더밀착수학 앱 화면이 열려요.
  3. 홈 화면에 추가화면 아래 가운데 공유 버튼 → 목록을 조금 올려 홈 화면에 추가 → 오른쪽 위 추가
  4. 홈 화면의 더밀착수학 아이콘으로 열기꼭 아이콘으로 여셔야 알림을 받을 수 있어요.
  5. 가입하기처음이에요 · 가입하기 → 교습소에 알려주신 휴대폰 번호 + 원하는 비밀번호 → 선생님 승인 후 바로 이용
  6. 알림 받기 → 허용홈 화면 위쪽 알림 받기를 누르고 허용. (iOS 16.4 이상)
  1. 아래 [크롬에서 앱 열기] 버튼 누르기갤럭시 기본 인터넷이 아니라 크롬(Chrome)으로 열려요. 크롬에서 열어야 알림이 잘 와요.
  2. 앱 설치앱 화면 아래 설치 또는 앱 설치하기를 누르세요. 안 보이면 크롬 오른쪽 위 ⋮ → 홈 화면에 추가 → 설치
  3. 홈 화면의 더밀착수학 아이콘으로 열기이제부터는 아이콘으로 바로 열면 돼요.
  4. 가입하기처음이에요 · 가입하기 → 교습소에 알려주신 휴대폰 번호 + 원하는 비밀번호 → 선생님 승인 후 바로 이용
  5. 알림 받기 → 허용홈 화면 위쪽 알림 받기 → 허용. 허용 창이 안 뜨면 아이콘 길게 누르기 → ⓘ 앱 정보 → 알림 → 알림 허용
가입은 교습소에 등록된 번호로만 할 수 있어요. 등록이 안 됐다고 나오면 선생님께 번호를 알려 주세요.

자주 묻는 질문

앱스토어·플레이스토어에서 받는 앱인가요?

아니요. 교습소 전용 웹앱이라 스토어 없이 홈 화면에 추가하면 일반 앱처럼 쓸 수 있어요. 용량도 거의 차지하지 않아요.

업데이트는 어떻게 하나요?

따로 할 필요 없어요. 새 기능이 생기면 알림이 오고, 앱을 열면 자동으로 새 버전이 적용돼요.

알림이 오지 않아요

아이폰은 홈 화면 아이콘으로 연 앱에서만 알림이 돼요. 갤럭시는 크롬으로 설치했는지 확인해 주세요. 앱 홈의 [알림 받기]를 한 번 더 눌러 보시고, 그래도 안 되면 선생님께 말씀해 주세요.

개인정보는 안전한가요?

등록된 가족만 가입할 수 있고, 학부모님은 자기 자녀 정보만 볼 수 있어요. 다른 학생이나 가족의 정보는 보이지 않아요.

비밀번호를 잊어버렸어요

선생님께 말씀해 주시면 다시 가입할 수 있게 해 드려요.
